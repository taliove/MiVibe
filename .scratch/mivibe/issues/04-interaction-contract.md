# 录音与直接输入的异常行为如何确定

## Question

基于研究，与用户确定录音中切换应用、网络超时、失焦、连续录音时的目标与文字保留行为，以及可理解的状态反馈。

## Answer

2026-09-08：用户以“按建议”确认以下四项建议。本票解决产品行为，不代表已实现或通过真机验证。

1. 录音或等待结果期间切换软件/输入目标：暂停自动输入并暂存结果；用户选好输入框后显式点击“输入到这里”。正常路径保持松手直接输入，不新增确认步骤。
2. 断网或转写失败：保留本段录音供手动重试，成功后删除；已有文字但输入失败时保留文字。第一版不保存长期录音历史。失败内容的具体清理期限、退出行为另票确定，未默认为永久保存。
3. 前一句仍在转写时允许继续录音；按录音顺序输入。前一句失败时暂停后续自动输入，避免顺序混乱。并发数量、队列容量以及恢复/丢弃前一句后如何继续另票确定。
4. 屏幕底部显示不抢焦点的小浮条，状态为“正在听 / 正在转写 / 已输入 / 需处理”。录音或等待转写期间，遥控器返回键取消本次操作。多句并存时“本次”的精确目标及返回键与普通映射的优先级在交互原型中明确。
