# 日常使用验收、首次配对引导与安装分发边界如何定义

Type: grilling
Label: wayfinder:grilling
Status: resolved
Assignee: taliove (with Claude)
Parent: ../map.md

## Question

真机与 API 证据已齐备，定义第一版规格的三块收口内容：

1. **日常使用验收清单**：什么算"能用"——识别准确率体感、尾延迟上限（实测单遍 0.209s/二遍 0.767s）、连续录音可靠性、异常恢复的容忍度。
2. **首次配对引导**：未检测到已配对遥控器时的检测与指引体验（09 票已确定启动前检查的技术路径）。
3. **安装与分发边界**：个人使用的签名方式（ad-hoc/开发者签名/公证）、是否开源、配置（API Key）的首次录入流程。

## Context

三块都是规格级决策，直接决定"第一版产品与技术规格"这一目的地是否收敛。费用展示体验依赖控制台账单核对结果，不在本票。

## Answer

2026-09-09 拷问一轮，用户全票同意六项推荐，无追问分支：

1. **二遍识别默认开**（实测尾延迟 0.767s 可接受，换更准分句），设置留开关；验收按开二遍定。
2. **验收硬指标两条**：端到端按住→上屏 P95 < 1.5s；连续 10 次按住说话 10/10 上屏。准确率走主观验收，不设数字。
3. **首次配对引导**：菜单栏状态三态（未配对/已配对未连接/已连接）+ 内嵌图文指引 + "打开蓝牙设置"按钮，不用模态窗口。
4. **签名分发**：自签证书固定身份（授权不反复弹），仅限本机；不公证、不上架、暂不开源。
5. **API Key 录入**：应用内设置页粘贴一次 → Keychain，附"打开控制台"按钮；与配对引导共用"状态+设置"入口。
6. **验收终点**：用户本人连续一天真实使用无"想砸键盘"级问题 + 两条硬指标通过；验收清单（含 Codex 预设确认键发送一项，由既有决策推导）写进规格附录。
