MiVibe

按住说话，松手成文。

整套视觉从一个动作出发：声音变成文字。标志是三根声波接一个文本光标，一种品牌色贯穿所有"进行中"的语音阶段。应用图标、菜单栏、浮条、设置窗口、README 和 GitHub 社交卡片都用这一套。

现状

现在哪里不一致

图标是通用麦克风SF Symbols 的 mic.fill 放在蓝紫渐变上，和任何录音应用都分不开，也没表达"成文"。
README 用的是小米产品照仓库首页的主视觉是别人的硬件和工业设计，和应用内的自有视觉是两套语言，也有商标风险。
浮条三个进行中状态难以分辨正在听是蓝，正在转写是紫，正在改写是另一种紫，色相只差 20°，一眼看不出区别，也没有主次。
图标四周留了透明边macOS 26 起，边缘透明的旧式图标会被系统套上灰色底板，在程序坞里显得小一圈。新图标要按苹果圆角矩形满铺。
标志

声波接光标

左边三根高低不同的圆头竖条是声音，右边的工字光标是文字输入的位置。线条统一 8–9 单位粗、圆头，缩到 16 像素仍能认出。不再使用麦克风，也不出现遥控器外形，避免和小米的产品形象绑定。

字形占 64×64 的安全区，居中；三根声波高度比 20 : 44 : 28，最高的那根不超过光标。

应用图标

满铺苹果圆角矩形，内容边缘 865 px / 1024 画布，和系统自带应用在程序坞里一样大。深色图标用于 macOS 的深色图标模式。

放在程序坞里和旁边的应用对比（左右两个是示意用的占位图标）。

菜单栏

单色模板图标，四种状态

菜单栏图标是模板图（单色，随系统浅色 / 深色自动反色），不使用品牌色。录音时声波跳动，用户不看浮条也知道正在听。现在用的是系统麦克风符号，换成标志字形后和应用图标呼应。

色彩

一种品牌色管过程，语义色只管结果

进行中 = 潮汐青

正在听、正在转写、正在改写都是同一件事的不同阶段，统一用品牌色。三者靠图标和动效区分：实心 + 跳动声波、描边 + 转圈、渐变 + 闪光。

结果 = 语义色

已输入是绿，需处理是琥珀，提示是中性灰。结果色只在结束时出现，停留 2 秒左右，用户一眼知道成没成。

中性灰都略偏青，和品牌色同一色温。设置窗口的开关、选中项和链接统一改用品牌色，不再用系统默认蓝。

品牌色有三个候选

A · 潮汐青
推荐

和系统蓝、琥珀、成功绿都拉得开，深色和浅色背景上都清楚；声音、水波的联想和产品贴合，也和小米橙、苹果蓝都不撞。

B · 靛蓝延续

沿用现在图标的色系，老用户最熟悉。缺点是和系统强调色（蓝）太近，设置窗口里分不出哪些是 MiVibe 自己的颜色，而且蓝紫渐变很常见。

C · 珊瑚红

"录音中"的直觉最强（像录音红点）。但红色容易被读成出错，又和小米橙接近，需处理的琥珀色也得跟着改。
