正在听预览
主题只管应用内影响浮条、设置窗口、菜单弹层里的强调色。应用图标、README 和 GitHub 图始终用品牌默认色，品牌识别不会因为用户换主题而变。
语义色不开放已输入、需处理、提示三种颜色固定，保证任何主题下"成功"和"要处理"都一眼能分清。
跟随系统外观浮条默认随 macOS 浅色 / 深色切换，也可以固定一种。菜单栏图标始终是系统模板图，不受影响。
存储配置里新增两个可选字段（外观、主题色），旧配置缺字段时回落默认值，不影响已有的 API Key 等设置。
需要你定
  1. 品牌默认色选哪一套？README、图标、社交图用它。
  2. 主题选择里放哪几套？可以全放六套，也可以只放三四套。
  3. 浮条外观要不要允许固定为浅色或深色，还是只跟随系统？
